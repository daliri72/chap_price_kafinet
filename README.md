# نرخنامه هوشمند کافی‌نت آینده

اپلیکیشن فارسی RTL برای جستجوی تعرفه‌های چاپ و کپی و صدور فاکتور.

## اجرا
فایل `index.html` را با Chrome یا Edge باز کنید. نیازی به نصب، سرور یا اینترنت نیست.

## GitHub Pages
فایل‌ها را در ریشه یک Repository عمومی قرار دهید. Settings → Pages → Deploy from a branch → main / (root). فایل `.nojekyll` برای انتشار ساده همراه پروژه است.

## امکانات فعلی
- تم روشن، هدر فشرده و امضای متحرک طراحی
- جستجوی لحظه‌ای دسته‌های نرخنامه، با معادل‌سازی «کپی» و «زیراکس»
- افزودن خدمات به فاکتور و ویرایش تعداد؛ ردیف خدمات اختصاصی، تخفیف و هزینه اضافه
- اطلاعات مشتری، شماره فاکتور و تاریخ؛ چاپ A4
- اسکرول ردیف‌های فاکتور در نمایش، بدون محدود شدن ردیف‌ها در چاپ
- پنهان کردن سربرگ و پابرگ مخصوص برنامه در فاکتور چاپی
- ویرایش فی واحد هر ردیف در همان فاکتور
- ذخیرهٔ خودکار پیش‌نویس و بازیابی آن پس از باز کردن دوبارهٔ برنامه
- تاریخچهٔ فاکتورها، ویرایش و چاپ مجدد، و دریافت و بازیابی پشتیبان JSON

## ذخیره و بازیابی

با تغییر فرم یا ردیف‌ها، پیش‌نویس خودکار ذخیره می‌شود. فاکتور دارای نام مشتری، حداقل یک ردیف و تخفیف معتبر در تاریخچه هم ذخیره می‌شود. ویرایش، همان فاکتور را به‌روزرسانی می‌کند و چاپ مجدد از تاریخچه، فرم باز را تغییر نمی‌دهد.

از «تاریخچه و پشتیبان» می‌توانید فایل JSON شامل فاکتورها و پیش‌نویس را دریافت کنید. بازیابی، فاکتورهای پشتیبان را به تاریخچهٔ موجود اضافه می‌کند. برای شناسهٔ یکسان با محتوای متفاوت، هر دو نسخه نگه داشته می‌شوند. اگر پیش‌نویس باز با پیش‌نویس پشتیبان متفاوت باشد، برنامه پیش از جایگزینی تأیید می‌گیرد.

اطلاعات در حافظهٔ محلی همان مرورگر و نشانی ذخیره می‌شود. نسخهٔ محلی و نسخهٔ GitHub Pages حافظه‌های جداگانه دارند. برای جابه‌جایی بین آن‌ها یا مرورگرها، از پشتیبان JSON استفاده کنید. پاک کردن داده‌های مرورگر ممکن است تاریخچه را حذف کند. فایل پشتیبان حاوی اطلاعات مشتریان است و باید خارج از مخزن عمومی نگهداری شود.

## چاپ

برای حذف آدرس، تاریخ یا شمارهٔ صفحه‌ای که مرورگر به برگه اضافه می‌کند، گزینهٔ «سربرگ‌ها و پابرگ‌ها» را در پنجرهٔ چاپ Chrome یا Edge غیرفعال کنید.
